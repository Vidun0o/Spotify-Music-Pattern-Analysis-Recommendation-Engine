# Spotify-Music-Pattern-Analysis-Recommendation-Engine
Analyzing 1.2M+ tracks using Spotipy and Kaggle datasets. This engine uses K-Means clustering (optimized via Elbow/Silhouette methods) to group songs into "vibe" categories. Features PCA/t-SNE for 2D visualization and a Cosine Similarity recommender to find the top 5 acoustically similar tracks. Developed in Python.
